# Curated Handwritten Fonts

This directory contains open-source handwritten and script fonts optimized for rendering high-resolution wallpapers.

| Font Family | Style / Feel | Designer / Foundary | License |
| :--- | :--- | :--- | :--- |
| **Architects Daughter** | Architectural monoline, raw stick lettering | Kimberly Geswein | SIL Open Font License, 1.1 |
| **Caveat** | Dynamic natural handwriting | Impallari Type | SIL Open Font License, 1.1 |
| **Indie Flower** | Carefree, open & rounded handwriting | Kimberly Geswein | SIL Open Font License, 1.1 |
| **Patrick Hand** | Neat teacher / notebook handwriting | Patrick Wagesreiter | SIL Open Font License, 1.1 |
| **Shadows Into Light** | Clean, neat feminine handwriting | Kimberly Geswein | SIL Open Font License, 1.1 |
| **Amatic SC** | Narrow condensed display lettering | Vernon Adams | SIL Open Font License, 1.1 |
| **Reenie Beanie** | Thin delicate ballpoint pen script | James Grieshaber | SIL Open Font License, 1.1 |
| **Rock Salt** | Felt-tip marker graffiti lettering | Sideshow | Apache License, Version 2.0 |

All fonts are sourced from [Google Fonts](https://fonts.google.com/) and are freely usable for personal and commercial projects.
